TaskNest – Full-Stack Project Management Platform

TaskNest is a full-stack project management application inspired by tools like Trello, designed to help teams and individuals organize tasks, manage workflows, and improve productivity.

This solution is built as two separate projects:

TaskNest.UI → A modern frontend built with Blazor
TaskNest.API → A scalable backend built with ASP.NET Core Web API

Together, they provide a seamless task management experience with real-time collaboration, secure authentication, and efficient project tracking.

📌 Project Architecture
TaskNest/
│
├── TaskNest.UI/          # Blazor Frontend Application
├── TaskNest.API/         # ASP.NET Core Web API Backend
└── README.md
🚀 Features
🔹 Frontend (Blazor UI)
Modern and responsive user interface
Interactive dashboards
Task boards with drag-and-drop workflow
User-friendly forms and validations
Authentication integration
Real-time updates and smooth navigation
🔹 Backend (ASP.NET Core API)
RESTful API architecture
Secure JWT authentication & authorization
CRUD operations for boards, lists, and tasks
Role-based access control
Database integration with Entity Framework Core
Scalable and maintainable service structure
🛠️ Tech Stack
Frontend
Blazor
C#
HTML / CSS / JavaScript
Backend
ASP.NET Core Web API
Entity Framework Core
SQL Server
JWT Authentication
